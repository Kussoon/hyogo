# 兵庫県 名産品記憶ゲーム

第4段階までのデータ・学習画面・2種類のクイズ一式です。

- `index.html`：名産品ゲームのトップ
- `study.html`：地域・名産品を選んで場所を地図で確認する学習画面
- `quiz1.html`：名産品を見て、市町・区または10区域を地図で選ぶクイズ
- `quiz2.html`：光る場所を見て、4つの名産品から答えるクイズ
- `meisan-data.js`：全71問の出題データ、正答範囲、情報源
- `sources.html`：利用者向けの「出典・データについて」ページ

このフォルダを、兵庫県市町村記憶ゲームのリポジトリ直下へ追加します。`study.html`、`quiz1.html`、`quiz2.html` は、親フォルダの `hyogo-city.topojson` を読み込みます。
