# 兵庫県 名産品記憶ゲーム

第2段階までのデータ・学習画面一式です。

- `index.html`：名産品ゲームのトップ
- `study.html`：地域・名産品を選んで場所を地図で確認する学習画面
- `meisan-data.js`：全71問の出題データ、正答範囲、情報源
- `sources.html`：利用者向けの「出典・データについて」ページ

このフォルダを、兵庫県市町村記憶ゲームのリポジトリ直下へ追加します。`study.html` は、親フォルダの `hyogo-city.topojson` を読み込みます。次の段階で、同じフォルダ内に地図クイズと4択クイズのページを追加します。
