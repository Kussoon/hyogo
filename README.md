# 兵庫県 市町村記憶ゲーム

Ver.3.0.2

兵庫県の40市町＋神戸市9区、49区域を覚える学習ゲームです。

公開URL：<https://kussoon.github.io/hyogo/>

## 構成

- `index.html`：トップページ
- `study-all.html`：全域市町村地図
- `study-region.html`：地域別学習
- `quiz1.html`：名前を見て、その場所を地図で選ぶ
- `quiz2.html`：地図上の場所を見て、名前を当てる

## 地域区分

神戸／阪神南／阪神北／東播磨／北播磨／中播磨／西播磨／但馬／丹波／淡路

## 主な機能

- 全域・地域別学習
- 地域別／全域クイズ
- 間違えた問題だけ再挑戦
- 採点
- 出題範囲の選び直し
- 地図の拡大／縮小／全体表示

## 地図データ

『歴史的行政区域データセットβ版』（CODH作成）／国土数値情報「行政区域データ」を加工。CC BY 4.0
