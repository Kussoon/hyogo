# 兵庫県 市町村記憶ゲーム

Ver.2.6.1

兵庫県内の40市町と神戸市9区、合計49区域の名前・形・位置関係を覚えるための非公式な学習用ウェブサイトです。

公開URL：<https://kussoon.github.io/hyogo/>

## 現在の構成

- `index.html`：トップページ
- `study-all.html`：兵庫県全域市町村地図
- `study-region.html`：10地域に分けた地域別学習モード
- `quiz1.html`：クイズ1「名前 → 場所」
- `quiz2.html`：クイズ2「場所 → 名前」

## 学習対象

40市町＋神戸市9区＝49区域

地域区分：
神戸／阪神南／阪神北／東播磨／北播磨／中播磨／西播磨／但馬／丹波／淡路

## 今後の予定

- 間違えた問題だけ再挑戦
- 出題範囲選択
