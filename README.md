兵庫県 市町村記憶ゲーム

兵庫県内の市町・神戸市9区の名前と位置関係を覚えるための、個人制作による非公式な学習用ウェブサイトです。

公開URL：https://kussoon.github.io/hyogo/

学習対象

兵庫県内の自治体を、次の49区域として扱います。

• 神戸市：9区をそれぞれ独立して扱う
  • 東灘区
  • 灘区
  • 兵庫区
  • 長田区
  • 須磨区
  • 垂水区
  • 北区
  • 中央区
  • 西区
• 神戸市以外：市町単位で扱う

合計：40市町＋神戸市9区＝49区域

※町は、学習時の正式表記として郡名を含めて扱います。
例：川辺郡猪名川町、加古郡稲美町、神崎郡福崎町、美方郡新温泉町 など。

現在の開発状況

現在は、正確な行政区域データを使った学習モードを制作中です。

実装済み：

• 兵庫県全体の行政区域地図
• 神戸市9区の区分表示
• 49区域の名称表示
• 区域タップ時の強調表示
• 拡大・縮小
• 全体表示
• スマートフォン表示対応

現在、阪神地域・神戸市9区など、区域が密集する場所のラベル位置を調整しています。

今後の予定

1. 学習モードのラベル配置調整
2. 地域別学習
3. 「市町・区名 → 場所」を当てるクイズ
4. 「場所 → 市町・区名」を当てるクイズ
5. 間違えた問題だけの再挑戦
6. トップページ・メニュー画面の整備

地図データ

行政区域の形状は、AI生成画像ではなく、実際の行政区域データを使用しています。

出典：

• 『歴史的行政区域データセットβ版』（CODH作成）
• 国土数値情報「行政区域データ」

データ配信：

• Geoshape / NII

本サイトでは、上記データを学習用に加工して表示しています。
